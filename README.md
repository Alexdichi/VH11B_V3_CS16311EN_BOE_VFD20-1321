# VH11B_V3_CS16311EN_BOE_VFD20-1321
Arduino library and technical documentation for the VH11B-V3 board using the CS16311EN VFD controller and BOE VFD20-1321 display. Based on real hardware reverse engineering and empirical testing. Supports 14-segment text, icons, bars and keyboard input for DIY, HAM radio and instrumentation projects.
